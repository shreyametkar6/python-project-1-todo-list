# Python Project 1: To-Do List

A command-line To-Do List built in Python (Jupyter Notebook) for the
DecodeLabs Industrial Training Kit, Batch 2026.

## Features
- Add tasks
- View numbered tasks (using `enumerate`)
- Input validation (empty tasks, invalid menu choices)
- Tasks saved to `tasks.json`, so they persist after restart
- Tasks stored as dictionaries: `{"id": 1, "task": "Buy Milk"}`
- Data logic separated from the user interface (functions)
- `if __name__ == "__main__":` entry point

## Concepts used
Lists, `append()`, `for` loops, `enumerate()`, dictionaries, functions,
`while` loop, file handling, JSON, `try/except`.

## How to run
Open `To-Do List.ipynb` in Jupyter Notebook, choose Kernel > Restart & Run All,
and use the menu in the last cell.
